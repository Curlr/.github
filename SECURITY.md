# Security Policy

## Supported versions

Curlr is currently in beta. Security fixes are applied to the latest available release.

## Reporting a vulnerability

Please do not open a public GitHub issue or post exploit details in public community channels.

Email **security@curlr.dev** with only enough information to begin a private, coordinated report. A maintainer will reply with a safe channel for additional details.

Please include:

- A short description of the potential impact
- The affected Curlr version and operating system
- High-level reproduction steps
- Your preferred contact information

Never send live API keys, passwords, access tokens, cookies, authorization headers, private URLs, customer data, or unredacted production logs. If a credential may have been exposed, revoke or rotate it immediately.

We appreciate responsible disclosure and will coordinate remediation and publication when appropriate.
