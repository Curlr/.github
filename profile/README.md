# Curlr

**API client, not a platform.**

Curlr is a lightweight, local-first API client for developers on Windows, macOS, and Linux.

- **No login, no account, no cloud.** Open the app and start sending requests.
- **Local by default.** Nothing leaves your machine unless you choose.
- **Git-native collaboration.** Collections are plain YAML files that work naturally with Git.
- **Bring your own AI keys.** AI features run only when you configure a provider.
- **Small and native.** Curlr is built with Tauri, a Rust core, and a focused web UI.

## What Curlr supports

HTTP and HTTPS, GraphQL, SSE and streaming responses, environments and variables, pre-request and post-response scripts, Bearer/Basic/API key/OAuth/AWS SigV4/Hawk authentication, file uploads, cookies, history, saved responses, collection runs, and imports from Postman, Insomnia, Bruno, OpenAPI, HAR, and curl.

## Security and privacy

Never include API keys, access tokens, cookies, authorization headers, private URLs, customer data, or unredacted request logs in public reports.

For security vulnerabilities, email [security@curlr.dev](mailto:security@curlr.dev). Please include only enough information to begin a private, coordinated report.
