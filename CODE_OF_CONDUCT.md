# Curlr Community Code of Conduct

Curlr is building a calm, technical, and constructive community for API developers.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and implementations, not people.
- Share reproducible technical details with secrets removed.
- Respect privacy, confidentiality, and coordinated vulnerability disclosure.
- Help keep discussions useful for developers across experience levels and platforms.

## Unacceptable behavior

Harassment, discrimination, threats, impersonation, spam, malicious links, deliberate disruption, or publishing another person's confidential information are not tolerated.

## Enforcement

Maintainers may edit or remove content, restrict participation, or take other proportionate action to protect the community. Serious or repeated violations may result in permanent removal.

Report conduct concerns privately to **info@curlr.dev**. Report security vulnerabilities to **security@curlr.dev**.
